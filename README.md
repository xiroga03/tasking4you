# Tasking4You – TaskBoard

Aplicación web para la gestión y organización de tareas personales, desarrollada como proyecto académico de Ingeniería Web.

## Objetivo

Construir una plataforma web que permita crear, consultar, actualizar y eliminar tareas, facilitando la organización de actividades y el seguimiento de su estado.

## Tecnologías

### Frontend
- React
- Vite
- JavaScript
- CSS responsive

### Backend
- Node.js
- Express
- API REST

### Base de datos
- PostgreSQL

### Herramientas
- Git y GitHub
- Visual Studio Code
- Render
- Cloudflare

## Funcionalidades principales

- Crear tareas.
- Consultar el listado de tareas.
- Marcar tareas como completadas o pendientes.
- Eliminar tareas.
- Validar campos obligatorios.
- Guardar información de forma persistente.
